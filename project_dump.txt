## 📌 О проекте

**Anti-Fraud Monitor** — многомодульное Spring Boot-приложение, которое принимает платёжные транзакции, асинхронно прогоняет их через набор антифрод-правил и присваивает итоговое решение:

| Статус | Значение |
|:---|:---|
| `NEW` | Транзакция принята и сохранена, скоринг ещё не выполнен |
| `APPROVED` | Ни одно правило не сработало |
| `REVIEW` | Сработали правила уровня `MEDIUM`/`HIGH` — требуется ручная проверка |
| `DECLINED` | Сработало хотя бы одно правило уровня `CRITICAL` |

**Бизнес-задача.** Банк или платёжный провайдер должен быстро принимать поток транзакций, не блокируя приём тяжёлой аналитикой, и при этом фиксировать *почему* транзакция была помечена подозрительной. Проект решает её через:

- **разделение write- и read-стороны** (приём / скоринг / чтение результатов — три независимых сервиса);
- **асинхронный скоринг** через Kafka — приём отвечает `202 Accepted` сразу после сохранения;
- **расширяемый движок правил** (паттерн *Guard*) — новое правило добавляется одним `@Component`;
- **аудируемость** — каждое сработавшее правило сохраняется как отдельный `Alert` с severity и текстовым пояснением.

### Жизненный цикл транзакции

```mermaid
sequenceDiagram
    autonumber
    participant C as Клиент
    participant G as gateway
    participant I as ingestion
    participant DB as PostgreSQL
    participant K as Kafka
    participant S as scoring
    participant R as Redis

    C->>G: POST /api/v1/transactions
    G->>I: проксирование
    I->>DB: existsByExternalId? (идемпотентность)
    I->>DB: INSERT transaction (status = NEW)
    I->>K: send(transactions.raw, key = cardToken)
    I-->>C: 202 Accepted {transactionId, status: NEW}

    K->>S: TransactionEvent
    S->>R: SETNX processed:event:{externalId} (TTL 24h)
    S->>DB: findByExternalId
    S->>S: GuardFilterService → AmountThreshold, HighRiskMerchant, Velocity
    S->>R: INCR velocity:card:{cardToken} (TTL 5 мин)
    S->>DB: INSERT alerts + UPDATE status (APPROVED / REVIEW / DECLINED)

    C->>G: GET /api/v1/transactions
    G->>DB: через alerting (read-only)
```

### Назначение модулей

| Модуль | Роль | Порт | Postgres | Kafka | Redis | Тип |
|:---|:---|:---:|:---:|:---:|:---:|:---|
| **`common`** | Общая модель: JPA-сущности, репозитории, enum-ы, Kafka-контракт `TransactionEvent`, доменное исключение | — | — | — | — | Библиотека (jar) |
| **`ingestion`** | Приём транзакции: валидация, проверка дубликата по `externalId`, сохранение со статусом `NEW`, публикация события | `8081` | RW | producer | — | Spring MVC |
| **`scoring`** | Потребление событий, запуск всех `Guard`-правил, создание `Alert`-ов, расчёт итогового статуса | — | RW | consumer | RW | Non-web (только Kafka) |
| **`alerting`** | Только чтение: список транзакций (с алертами и маскированным номером карты) и список алертов | `8082` | RO | — | — | Spring MVC |
| **`gateway`** | Маршрутизация внешнего трафика к `ingestion` / `alerting` по пути и HTTP-методу | `8080` | — | — | — | Spring WebFlux |

### Взаимодействие компонентов

- **Синхронный путь** (`клиент → gateway → ingestion/alerting`): HTTP. `gateway` разводит запросы по паре *путь + метод* — `POST /api/v1/transactions` уходит в `ingestion`, `GET`-запросы — в `alerting`.
- **Асинхронный путь** (`ingestion → Kafka → scoring`): топик `transactions.raw`, ключ сообщения — `cardToken` (все транзакции одной карты попадают в одну партицию и обрабатываются строго по порядку), значение — JSON `TransactionEvent`.
- **Общая БД.** Все три сервиса работают с одной схемой PostgreSQL `antifraud` через общие сущности из `common`. Событие в Kafka содержит бизнес-данные, но `scoring` перечитывает транзакцию из БД по `externalId` — БД остаётся источником истины.
- **Redis** используется только `scoring`: для скользящего счётчика velocity и для дедупликации событий.

## 🎯 Основной функционал

### 1. Приём транзакций (`ingestion`)

- Валидация входящего запроса (Bean Validation):
    - `externalId`, `currency`, `merchantCountry`, `occurredAt` — обязательны;
    - `cardToken`, `merchantName` — не пустые, ≤ 255 символов;
    - `amount` — строго положительный, до 15 знаков в целой и 4 в дробной части;
    - `occurredAt` — не в будущем (`@PastOrPresent`).
- **Идемпотентность по `externalId`**: повторная отправка той же транзакции → `409 Conflict`.
- Сохранение в БД со статусом `NEW`, затем публикация `TransactionEvent` в Kafka.
- Ответ `202 Accepted` с заголовком `Location` и телом `{ transactionId, status }`.
- Единый обработчик ошибок (`@RestControllerAdvice`): `400` (невалидное тело / поля), `409` (дубликат).

### 2. Антифрод-скоринг (`scoring`)

Движок построен на интерфейсе `Guard` — каждое правило независимо и возвращает `Optional<GuardViolation>`. `GuardFilterService` автоматически подхватывает **все** бины `Guard` и для каждого нарушения создаёт `Alert`.

| Правило (`Rule`) | Severity | Логика |
|:---|:---:|:---|
| `AMOUNT_THRESHOLD` | `MEDIUM` | Сумма **строго больше** порога для валюты: EUR/CHF — 5 000, CAD — 7 000, AUD — 8 000, BRL — 30 000, JPY — 800 000 |
| `HIGH_RISK_MERCHANT` | `HIGH` | Точное совпадение (регистрозависимое) `merchantName` с: `Casino`, `Online Poker`, `Crypto Exchange`, `Gambling`, `Wire Transfer` |
| `VELOCITY` | `CRITICAL` | Более **5** транзакций по одной карте за **5 минут** (Redis `INCR` + `EXPIRE`, ключ `velocity:card:{cardToken}`). При недоступности значения из Redis правило *fail-open* — не срабатывает |

**Расчёт итогового статуса:**

```text
нет алертов                  → APPROVED
есть алерты, нет CRITICAL    → REVIEW
есть хотя бы один CRITICAL   → DECLINED
```

**Надёжность обработки:**

- **Дедупликация событий** — `SET processed:event:{externalId} NX EX 24h` в Redis; повторная доставка того же события пропускается.
- **Retry с экспоненциальной паузой** — `@RetryableTopic(backOff = @BackOff(delay = 2000, multiplier = 2.0))`: Spring Kafka автоматически создаёт retry-топики и DLT.
- Consumer-метод выполняется в транзакции БД (`@Transactional`).

### 3. Чтение результатов (`alerting`)

- Список всех транзакций вместе с вложенными алертами.
- **Маскирование номера карты**: наружу отдаётся `**** 1234` (последние 4 символа токена), полный `cardToken` через API транзакций не раскрывается.
- Список всех сработавших алертов (`rule`, `severity`, `message`, `createdAt`).
- Все запросы выполняются в `@Transactional(readOnly = true)`.

### 4. Единая точка входа (`gateway`)

- Маршрутизация по пути и HTTP-методу, адреса апстримов переопределяются переменными `INGESTION_URI` и `ALERTING_URI`.
- Actuator-эндпоинты `health`, `info`, `gateway` (просмотр маршрутов).

## 🚀 Сборка и запуск

Предусмотрено два режима: **A — инфраструктура в Docker, сервисы локально** (удобно для разработки) и **B — всё в контейнерах**.

### Режим A. Инфраструктура в Docker, сервисы локально

**1. Поднять инфраструктуру** (PostgreSQL, Redis, Kafka, Kafka UI):

```bash
docker compose up -d postgres redis kafka kafka-ui
docker compose ps        # дождитесь статуса healthy у postgres, redis и kafka
```

**2. Собрать все модули:**

```bash
mvn clean install
# без тестов:
mvn clean install -DskipTests
```

**3. Запустить сервисы — каждый в отдельном терминале и именно в таком порядке:**

```bash
# 1) ingestion — создаёт схему БД (ddl-auto: update)
mvn -pl ingestion spring-boot:run

# 2) scoring — Kafka-consumer
mvn -pl scoring spring-boot:run

# 3) alerting — только после того, как схема создана (ddl-auto: validate)
mvn -pl alerting spring-boot:run

# 4) gateway — единая точка входа
mvn -pl gateway spring-boot:run
```

Либо запуск собранных jar-файлов:

```bash
java -jar ingestion/target/ingestion-0.0.1-SNAPSHOT.jar
java -jar scoring/target/scoring-0.0.1-SNAPSHOT.jar
java -jar alerting/target/alerting-0.0.1-SNAPSHOT.jar
java -jar gateway/target/gateway-0.0.1-SNAPSHOT.jar
```

> ⚠️ **Порядок запуска важен.** В проекте нет миграций Flyway/Liquibase: схему создаёт Hibernate (`ddl-auto: update`) в `ingestion` и `scoring`, а `alerting` работает в режиме `validate` и **не стартует на пустой БД**. Сначала запускайте `ingestion` (или `scoring`), потом `alerting`.

### Режим B. Всё в Docker Compose

```bash
docker compose up -d --build
docker compose logs -f ingestion scoring alerting gateway
```

> ℹ️ Compose собирает образы по `<module>/Dockerfile` с контекстом в корне репозитория (`ingestion/Dockerfile`, `scoring/Dockerfile`, `alerting/Dockerfile`, `gateway/Dockerfile`). Эти файлы должны лежать в репозитории рядом с модулями.
>
> Из-за той же особенности со схемой БД (см. выше) `alerting` может упасть при самом первом старте, если стартанул раньше `ingestion`. В этом случае достаточно: `docker compose restart alerting`.

**Тело запроса:**

| Поле | Тип | Ограничения |
|:---|:---|:---|
| `externalId` | UUID | обязательное, уникальное |
| `cardToken` | string | не пустое, ≤ 255 |

## 🗺 Планы по развитию / TODO

Список составлен по результатам анализа кода. Приоритеты: 🔴 высокий (корректность / безопасность), 🟡 средний, 🟢 низкий.

### 🔴 Корректность и надёжность

- [ ] **Идемпотентность в `scoring` может «терять» события при ретраях.** `TransactionEventConsumer` ставит Redis-ключ `processed:event:{externalId}` **до** обработки и не снимает его при ошибке. Если обработка упала (например, `TransactionNotFoundException`), повторная попытка из `@RetryableTopic` увидит ключ, молча завершится — а транзакция навсегда останется в `NEW`. Решение: ставить ключ после успешного коммита либо удалять его в `catch`/через `TransactionSynchronization`, либо перейти на идемпотентность на уровне БД (проверка статуса `NEW`).
- [ ] **Гонка между коммитом и публикацией события в `ingestion`.** `kafkaTemplate.send` вызывается внутри `@Transactional` метода до коммита: `scoring` может получить событие раньше, чем транзакция станет видна в БД. Решение — **Transactional Outbox** (таблица `outbox` + публикация отдельным поллером/Debezium) или публикация через `@TransactionalEventListener(phase = AFTER_COMMIT)`.
- [ ] **Velocity-счётчик не откатывается** при ретрае/ошибке: `INCR` выполняется до сохранения результата, повторная обработка завладеет «лишней» единицей и может дать ложный `CRITICAL`. Рассмотреть Lua-скрипт/скользящее окно на `ZSET` с привязкой к `occurredAt`.
- [ ] **Нет миграций БД.** Схему создаёт Hibernate (`ddl-auto: update`) в двух сервисах одновременно, а `alerting` в режиме `validate` падает на пустой БД. Внедрить **Flyway** или **Liquibase**, перевести все сервисы на `validate`.
- [ ] **Нет обработчика DLT.** После исчерпания ретраев сообщение уходит в Dead Letter Topic, но никто его не читает. Добавить `@DltHandler`, метрики и алертинг.
- [ ] **`Location`-заголовок ведёт в никуда.** `POST` возвращает `Location: /api/v1/transactions/{id}`, но `GET /api/v1/transactions/{id}` не реализован.

### 🔴 Безопасность

package com.zverev.alerting.service;

import com.zverev.alerting.dto.TransactionResponse;
import com.zverev.repository.TransactionRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

import static com.zverev.alerting.dto.TransactionResponse.toTransactionResponse;

@Service
public class TransactionQueryService {

    private final TransactionRepository transactionRepository;

    public TransactionQueryService(TransactionRepository transactionRepository) {
        this.transactionRepository = transactionRepository;
    }

    @Transactional(readOnly = true)
    public List<TransactionResponse> findAllTransactions() {
        return transactionRepository.findAllWithAlerts()
                .stream()
                .map(transaction -> {
                    String cardToken = transaction.getCardToken();
                    String cardTokenMasked = maskCard(cardToken);
                    return toTransactionResponse(transaction, cardTokenMasked);
                })
                .toList();
    }

    private String maskCard(String cardToken) {
        if (cardToken == null || cardToken.length() < 4) {
            return "****";
        }
        return "**** " + cardToken.substring(cardToken.length() - 4);
    }
}

package com.zverev.auth.controller;

import com.zverev.auth.dto.LoginRequest;
import com.zverev.auth.dto.LoginResponse;
import com.zverev.auth.security.JwtService;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import org.springframework.http.ResponseEntity;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("api/v1/auth")
@RequiredArgsConstructor
public class AuthController {

    private final AuthenticationManager authenticationManager;
    private final UserDetailsService userDetailsService;
    private final JwtService jwtService;

    @PostMapping("/login")
    public ResponseEntity<LoginResponse> login(@Valid @RequestBody LoginRequest request) {
        authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(request.getLogin(), request.getPassword())
        );

        UserDetails user = userDetailsService.loadUserByUsername(request.getLogin());
        String token = jwtService.generateToken(user);

        return ResponseEntity.ok(new LoginResponse(token));
    }
}

package com.zverev.auth.security;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.lang.NonNull;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;

@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtService jwtService;
    private final StaffUserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(
            @NonNull HttpServletRequest request,
            @NonNull HttpServletResponse response,
            @NonNull FilterChain filterChain
    ) throws ServletException, IOException {

        String authHeader = request.getHeader("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            filterChain.doFilter(request, response);
            return;
        }

        String jwt = authHeader.substring(7);
        String username = jwtService.extractUsername(jwt);

        if (username != null && SecurityContextHolder.getContext().getAuthentication() == null) {
            UserDetails userDetails = userDetailsService.loadUserByUsername(username);
            if (jwtService.isTokenValid(jwt, userDetails)) {
                var authToken = new UsernamePasswordAuthenticationToken(
                        userDetails, null, userDetails.getAuthorities()
                );
                authToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
                SecurityContextHolder.getContext().setAuthentication(authToken);
            }
        }

        filterChain.doFilter(request, response);
    }
}

package com.zverev.auth.security;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.stereotype.Service;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;

@Service
public class JwtService {

    private final SecretKey signingKey;
    private final long expirationMs;

    public JwtService(
            @Value("${security.jwt.secret}") String secret,
            @Value("${security.jwt.expiration-ms:86400000}") long expirationMs) {
        this.signingKey = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
        this.expirationMs = expirationMs;
    }

    public String generateToken(UserDetails userDetails) {
        Date now = new Date();
        return Jwts.builder()
                .subject(userDetails.getUsername())
                .claim("role", userDetails.getAuthorities().iterator().next().getAuthority())
                .issuedAt(now)
                .expiration(new Date(now.getTime() + expirationMs))
                .signWith(signingKey)
                .compact();
    }

    public String extractUsername(String token) {
        return parseClaims(token).getSubject();
    }

    public boolean isTokenValid(String token, UserDetails userDetails) {
        try {
            Claims claims = parseClaims(token);
            return claims.getSubject().equals(userDetails.getUsername())
                    && claims.getExpiration().after(new Date());
        } catch (Exception e) {
            return false;
        }
    }

    private Claims parseClaims(String token) {
        return Jwts.parser()
                .verifyWith(signingKey)
                .build()
                .parseSignedClaims(token)
                .getPayload();
    }
}

package com.zverev.auth.security;

import lombok.RequiredArgsConstructor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.dao.DaoAuthenticationProvider;
import org.springframework.security.config.annotation.authentication.configuration.AuthenticationConfiguration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

@Configuration
@EnableWebSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthenticationFilter;
    private final UserDetailsService userDetailsService;

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .csrf(AbstractHttpConfigurer::disable)
                .sessionManagement(session ->
                        session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/api/v1/auth/login").permitAll()
                        .requestMatchers("/actuator/health", "/actuator/info").permitAll()
                        .anyRequest().authenticated()
                )
                .authenticationProvider(authenticationProvider())
                .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

    @Bean
    public DaoAuthenticationProvider authenticationProvider() {
        DaoAuthenticationProvider provider = new DaoAuthenticationProvider(userDetailsService);
        provider.setPasswordEncoder(passwordEncoder());
        return provider;
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    @Bean
    public AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }
}

package com.zverev.auth.security;

import com.zverev.entity.Staff;
import com.zverev.entity.enums.StaffRole;
import com.zverev.repository.StaffRepository;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.boot.CommandLineRunner;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Component;

@Component
@RequiredArgsConstructor
@Slf4j
public class StaffDataInitializer implements CommandLineRunner {

    private final StaffRepository staffRepository;
    private final PasswordEncoder passwordEncoder;

    @Override
    public void run(String... args) {
        createIfAbsent("staff", "staff123");
        createIfAbsent("staff2", "staff123");
    }

    private void createIfAbsent(String login, String rawPassword) {
        if (staffRepository.existsByLogin(login)) {
            return;
        }
        Staff staff = Staff.builder()
                .login(login)
                .password(passwordEncoder.encode(rawPassword))
                .role(StaffRole.STAFF)
                .enabled(true)
                .build();
        staffRepository.save(staff);
        log.info("Created staff account: {}", login);
    }
}

package com.zverev.auth.security;

import com.zverev.entity.Staff;
import com.zverev.repository.StaffRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.core.userdetails.UsernameNotFoundException;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
public class StaffUserDetailsService implements UserDetailsService {

    private final StaffRepository staffRepository;

    @Override
    public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
        Staff staff = staffRepository.findByLogin(username)
                .orElseThrow(() -> new UsernameNotFoundException("Staff not found: " + username));

        return User.builder()
                .username(staff.getLogin())
                .password(staff.getPassword())
                .roles(staff.getRole().name())
                .disabled(!staff.isEnabled())
                .build();
    }
}

package com.zverev.entity;

import com.zverev.entity.enums.CurrencyCode;
import com.zverev.entity.enums.MerchantCountry;
import com.zverev.entity.enums.TransactionStatus;
import jakarta.persistence.CascadeType;
import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.EnumType;
import jakarta.persistence.Enumerated;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.OneToMany;
import jakarta.persistence.Table;
import lombok.AccessLevel;
import lombok.Builder;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

import java.math.BigDecimal;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

@Entity
@Table(name = "transactions")
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class Transaction {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "external_id", nullable = false, unique = true, updatable = false)
    private UUID externalId;

    @Column(name = "card_token", nullable = false, updatable = false)
    private String cardToken;

    @Column(nullable = false, precision = 19, scale = 4, updatable = false)
    private BigDecimal amount;

    @Enumerated(EnumType.STRING)
    @Column(name = "currency_code", nullable = false, length = 3, updatable = false)
    private CurrencyCode currencyCode;

    @Column(name = "merchant_name", nullable = false, updatable = false)
    private String merchantName;

    @Enumerated(EnumType.STRING)
    @Column(name = "merchant_country", nullable = false, updatable = false)
    private MerchantCountry merchantCountry;

    @Setter
    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 20)
    private TransactionStatus status;

    @Column(name = "occurred_at", nullable = false, updatable = false)
    private Instant occurredAt;

    @Column(name = "created_at", nullable = false, updatable = false)
    private Instant createdAt;

    @OneToMany(mappedBy = "transaction", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<Alert> alerts = new ArrayList<>();

    @Builder
    private Transaction(UUID externalId,
                        String cardToken,
                        BigDecimal amount,
                        CurrencyCode currencyCode,
                        String merchantName,
                        MerchantCountry merchantCountry,
                        Instant occurredAt,
                        Instant createdAt) {
        this.externalId = externalId;
        this.cardToken = cardToken;
        this.amount = amount;
        this.currencyCode = currencyCode;
        this.merchantName = merchantName;
        this.merchantCountry = merchantCountry;
        this.occurredAt = occurredAt;
        this.createdAt = createdAt;
        this.status = TransactionStatus.NEW;
    }

    public void addAlert(Alert alert) {
        alerts.add(alert);
        alert.setTransaction(this);
    }
}

package com.zverev.security;

import com.zverev.exception.InvalidJwtException;
import io.jsonwebtoken.Claims;
import io.jsonwebtoken.JwtException;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.time.Instant;
import java.util.Date;

public final class JwtUtils {

    private JwtUtils() {}

    public static SecretKey keyFrom(String secret) {
        byte[] bytes = secret.getBytes(StandardCharsets.UTF_8);
        if (bytes.length < 32) {
            throw new IllegalArgumentException(
                    "JWT secret must be at least 32 bytes for HS256, got " + bytes.length);
        }
        return Keys.hmacShaKeyFor(bytes);
    }

    public static String issue(String subject, long ttlSeconds, SecretKey key) {
        Instant now = Instant.now();
        Instant exp = now.plusSeconds(ttlSeconds);

        return Jwts.builder()
                .subject(subject)
                .issuedAt(Date.from(now))
                .expiration(Date.from(exp))
                .signWith(key, Jwts.SIG.HS256)
                .compact();
    }

    public static JwtClaims parse(String token, SecretKey key) {
        try {
            Claims payload = Jwts.parser()
                    .verifyWith(key)
                    .build()
                    .parseSignedClaims(token)
                    .getPayload();

            String sub = payload.getSubject();
            Date issuedAt = payload.getIssuedAt();
            Date expiration = payload.getExpiration();

            if (sub == null || issuedAt == null || expiration == null) {
                throw new InvalidJwtException("JWT missing required claims: sub, iat, exp");
            }

            return new JwtClaims(sub, issuedAt.toInstant(), expiration.toInstant());
        } catch (JwtException | IllegalArgumentException e) {
            throw new InvalidJwtException("Invalid JWT: " + e.getMessage(), e);
        }
    }
}

package com.zverev.gateway.filter;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.cloud.gateway.filter.GlobalFilter;
import org.springframework.core.Ordered;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatus;
import org.springframework.http.server.reactive.ServerHttpRequest;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;

@Component
public class JwtAuthenticationFilter implements GlobalFilter, Ordered {

    private final SecretKey signingKey;

    public JwtAuthenticationFilter(@Value("${security.jwt.secret}") String secret) {
        this.signingKey = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        ServerHttpRequest request = exchange.getRequest();
        String path = request.getURI().getPath();

        if ("OPTIONS".equals(request.getMethod().name()) || isWhitelisted(path)) {
            return chain.filter(exchange);
        }

        String authHeader = request.getHeaders().getFirst(HttpHeaders.AUTHORIZATION);
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }

        String token = authHeader.substring(7);
        try {
            Claims claims = Jwts.parser()
                    .verifyWith(signingKey)
                    .build()
                    .parseSignedClaims(token)
                    .getPayload();

            ServerHttpRequest mutated = request.mutate()
                    .header("X-Staff-Login", claims.getSubject())
                    .header("X-Staff-Role", String.valueOf(claims.get("role")))
                    .build();

            return chain.filter(exchange.mutate().request(mutated).build());

        } catch (Exception e) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
    }

    private boolean isWhitelisted(String path) {
        if (path.equals("/api/v1/auth/login")) {
            return true;
        }
        return path.startsWith("/actuator")
                || path.startsWith("/v3/api-docs")
                || path.startsWith("/swagger-ui")
                || path.startsWith("/webjars");
    }

    @Override
    public int getOrder() {
        return Ordered.HIGHEST_PRECEDENCE;
    }
}

package com.zverev.ingestion.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(TransactionAlreadyExistsException.class)
    @ResponseStatus(HttpStatus.CONFLICT)
    public Map<String, String> handleDuplicate(TransactionAlreadyExistsException ex) {
        return Map.of(
                "error", "duplicate_transaction",
                "message", ex.getMessage(),
                "externalId", ex.getExternalId().toString()
        );
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Map<String, String> handleUnreadable(HttpMessageNotReadableException ex) {
        return Map.of("error", "Invalid request body: "
                + ex.getMostSpecificCause().getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Map<String, String> handleValidation(MethodArgumentNotValidException ex) {
        String msg = ex.getBindingResult().getFieldErrors().stream()
                .map(e -> e.getField() + ": " + e.getDefaultMessage())
                .reduce((a, b) -> a + "; " + b)
                .orElse("Validation failed");
        return Map.of("error", msg);
    }
}

package com.zverev.ingestion.service;

import com.zverev.dto.TransactionEvent;
import com.zverev.entity.Transaction;
import com.zverev.ingestion.dto.TransactionCreatedResponse;
import com.zverev.ingestion.dto.TransactionRequest;
import com.zverev.ingestion.exception.TransactionAlreadyExistsException;
import com.zverev.ingestion.kafka.TransactionEventProducer;
import com.zverev.repository.TransactionRepository;
import lombok.AllArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;
import java.util.UUID;

@Service
@AllArgsConstructor
public class TransactionService {

    private final TransactionRepository transactionRepository;
    private final TransactionEventProducer transactionEventProducer;

    @Transactional
    public TransactionCreatedResponse process(TransactionRequest request) {
        UUID externalId = request.externalId();

        if (transactionRepository.existsByExternalId(externalId)) {
            throw new TransactionAlreadyExistsException(externalId);
        }

        Transaction transaction = Transaction.builder()
                .externalId(externalId)
                .cardToken(request.cardToken())
                .amount(request.amount())
                .currencyCode(request.currency())
                .merchantName(request.merchantName())
                .merchantCountry(request.merchantCountry())
                .occurredAt(request.occurredAt())
                .createdAt(Instant.now())
                .build();

        Transaction saved = transactionRepository.save(transaction);

        transactionEventProducer.send(
                new TransactionEvent(
                        saved.getExternalId(),
                        saved.getCardToken(),
                        saved.getAmount(),
                        saved.getCurrencyCode(),
                        saved.getMerchantName(),
                        saved.getMerchantCountry(),
                        saved.getOccurredAt()
                )
        );

        return new TransactionCreatedResponse(saved.getId(), saved.getStatus());
    }
}

package com.zverev.scoring.guard;

import com.zverev.entity.Transaction;
import com.zverev.entity.enums.AlertSeverity;
import com.zverev.entity.enums.CurrencyCode;
import com.zverev.entity.enums.Rule;
import com.zverev.scoring.dto.GuardViolation;
import org.springframework.stereotype.Component;

import java.math.BigDecimal;
import java.util.Map;
import java.util.Optional;

@Component
public class AmountThresholdGuard implements Guard {

    private static final Map<CurrencyCode, BigDecimal> THRESHOLDS = Map.of(
            CurrencyCode.EUR, new BigDecimal("5000"),
            CurrencyCode.CHF, new BigDecimal("5000"),
            CurrencyCode.CAD, new BigDecimal("7000"),
            CurrencyCode.AUD, new BigDecimal("8000"),
            CurrencyCode.BRL, new BigDecimal("30000"),
            CurrencyCode.JPY, new BigDecimal("800000")
    );

    @Override
    public Optional<GuardViolation> evaluate(Transaction transaction) {
        BigDecimal threshold = THRESHOLDS.get(transaction.getCurrencyCode());

        if (threshold != null && transaction.getAmount().compareTo(threshold) > 0) {
            return Optional.of(
                    new GuardViolation(
                            AlertSeverity.MEDIUM,
                            String.format("Amount %s %s exceeds threshold %s %s",
                                    transaction.getAmount(),
                                    transaction.getCurrencyCode(),
                                    threshold,
                                    transaction.getCurrencyCode())
                    )
            );
        }

        return Optional.empty();
    }

    @Override
    public Rule getRule() {
        return Rule.AMOUNT_THRESHOLD;
    }
}

package com.zverev.scoring.guard;

import com.zverev.entity.Transaction;
import com.zverev.entity.enums.AlertSeverity;
import com.zverev.entity.enums.Rule;
import com.zverev.scoring.dto.GuardViolation;
import lombok.RequiredArgsConstructor;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;

import java.time.Duration;
import java.util.Optional;

@Component
@RequiredArgsConstructor
public class VelocityGuard implements Guard {

    private static final String REDIS_KEY_PREFIX = "velocity:card:";
    private static final Duration WINDOW = Duration.ofMinutes(5);
    private static final int MAX_IN_WINDOW = 5;

    private final StringRedisTemplate stringRedisTemplate;

    @Override
    public Optional<GuardViolation> evaluate(Transaction transaction) {
        String key = REDIS_KEY_PREFIX + transaction.getCardToken();

        Long currentCount = stringRedisTemplate.opsForValue().increment(key);

        if (currentCount == null) {
            return Optional.empty();
        }

        if (currentCount == 1L) {
            stringRedisTemplate.expire(key, WINDOW);
        }

        if (currentCount > MAX_IN_WINDOW) {
            return Optional.of(
                    new GuardViolation(
                            AlertSeverity.CRITICAL,
                            String.format(
                                    "Velocity exceeded for card %s: %d transactions in last %d minutes",
                                    transaction.getCardToken(),
                                    currentCount,
                                    WINDOW.toMinutes()
                            )
                    )
            );
        }

        return Optional.empty();
    }

    @Override
    public Rule getRule() {
        return Rule.VELOCITY;
    }
}

package com.zverev.scoring.kafka;

import com.zverev.dto.TransactionEvent;
import com.zverev.entity.Alert;
import com.zverev.entity.Transaction;
import com.zverev.entity.enums.AlertSeverity;
import com.zverev.entity.enums.TransactionStatus;
import com.zverev.exception.TransactionNotFoundException;
import com.zverev.repository.TransactionRepository;
import com.zverev.scoring.service.GuardFilterService;
import lombok.AllArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.kafka.annotation.BackOff;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.annotation.RetryableTopic;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Duration;
import java.util.List;
import java.util.UUID;

@Service
@AllArgsConstructor
@Slf4j
public class TransactionEventConsumer {

    private static final String KAFKA_TOPIC = "transactions.raw";
    private static final String REDIS_KEY_PREFIX = "processed:event:";
    private static final Duration TTL = Duration.ofHours(24);

    private final TransactionRepository transactionRepository;
    private final GuardFilterService guardFilterService;
    private final StringRedisTemplate redisTemplate;

    @RetryableTopic(
            backOff = @BackOff(delay = 2000, multiplier = 2.0)
    )
    @KafkaListener(topics = KAFKA_TOPIC, groupId = "antifraud-group")
    @Transactional
    public void consume(TransactionEvent transactionEvent) {
        UUID externalId = transactionEvent.externalId();
        String key = REDIS_KEY_PREFIX + externalId;

        if (transactionEventIsAlreadyProcessed(key)) return;

        log.info("Processing transaction event: externalId={}", externalId);

        Transaction transaction = transactionRepository.findByExternalId(externalId)
                .orElseThrow(() -> new TransactionNotFoundException(externalId));

        guardFilterService.filter(transaction);

        List<Alert> alerts = transaction.getAlerts();
        TransactionStatus assignedStatus = assignStatus(alerts);
        transaction.setStatus(assignedStatus);

        transactionRepository.save(transaction);
        log.info("Transaction processed successfully: externalId={}, status={}",
                externalId, transaction.getStatus());
    }

    private boolean transactionEventIsAlreadyProcessed(String key) {
        Boolean isProcessed = redisTemplate.opsForValue()
                .setIfAbsent(key, "1", TTL);
        return Boolean.FALSE.equals(isProcessed);
    }

    private TransactionStatus assignStatus(List<Alert> alerts) {
        if (alerts.isEmpty()) {
            return TransactionStatus.APPROVED;
        }
        boolean hasCritical = alerts.stream()
                .anyMatch(a -> a.getSeverity() == AlertSeverity.CRITICAL);
        return hasCritical ? TransactionStatus.DECLINED : TransactionStatus.REVIEW;
    }
}

package com.zverev.scoring.service;

import com.zverev.entity.Alert;
import com.zverev.entity.Transaction;
import com.zverev.scoring.guard.Guard;
import org.springframework.stereotype.Service;

import java.time.Instant;
import java.util.List;

@Service
public class GuardFilterService {

    private final List<Guard> guards;

    public GuardFilterService(List<Guard> guards) {
        this.guards = guards;
    }

    public void filter(Transaction transaction) {
        guards.forEach(guard -> guard.evaluate(transaction)
                .ifPresent(violation -> {
                    Alert alert = new Alert(
                            guard.getRule(),
                            violation.severity(),
                            violation.message(),
                            Instant.now()
                    );
                    transaction.addAlert(alert);
                })
        );
    }
}

package com.zverev.scoring.guard;

import com.zverev.entity.Transaction;
import com.zverev.entity.enums.AlertSeverity;
import com.zverev.entity.enums.CurrencyCode;
import com.zverev.entity.enums.MerchantCountry;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.ValueOperations;

import java.math.BigDecimal;
import java.time.Duration;
import java.time.Instant;
import java.util.UUID;

import static org.assertj.core.api.Assertions.assertThat;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.ArgumentMatchers.anyString;
import static org.mockito.ArgumentMatchers.eq;
import static org.mockito.Mockito.never;
import static org.mockito.Mockito.verify;
import static org.mockito.Mockito.when;

@ExtendWith(MockitoExtension.class)
class VelocityGuardTest {

    @Mock
    private StringRedisTemplate redisTemplate;

    @Mock
    private ValueOperations<String, String> valueOps;

    private VelocityGuard guard;

    @BeforeEach
    void setUp() {
        guard = new VelocityGuard(redisTemplate);
        when(redisTemplate.opsForValue()).thenReturn(valueOps);
    }

    @Test
    @DisplayName("first transaction in window - sets TTL, no violation")
    void firstTransaction_setsTtl() {
        when(valueOps.increment("velocity:card:card-1")).thenReturn(1L);

        assertThat(guard.evaluate(tx("card-1"))).isEmpty();
        verify(redisTemplate).expire(eq("velocity:card:card-1"), any(Duration.class));
    }

    @Test
    @DisplayName("5th transaction - no violation, TTL not reset")
    void fifthTransaction_noViolation() {
        when(valueOps.increment("velocity:card:card-1")).thenReturn(5L);

        assertThat(guard.evaluate(tx("card-1"))).isEmpty();
        verify(redisTemplate, never()).expire(anyString(), any(Duration.class));
    }

    @Test
    @DisplayName("6th transaction - violation CRITICAL")
    void sixthTransaction_violation() {
        when(valueOps.increment("velocity:card:card-1")).thenReturn(6L);

        var result = guard.evaluate(tx("card-1"));

        assertThat(result).isPresent();
        assertThat(result.get().severity()).isEqualTo(AlertSeverity.CRITICAL);
        assertThat(result.get().message()).contains("6 transactions");
    }

    @Test
    @DisplayName("null from Redis - fail-open, no violation")
    void nullFromRedis_failOpen() {
        when(valueOps.increment("velocity:card:card-1")).thenReturn(null);

        assertThat(guard.evaluate(tx("card-1"))).isEmpty();
    }

    private Transaction tx(String cardToken) {
        return Transaction.builder()
                .amount(new BigDecimal("100"))
                .currencyCode(CurrencyCode.EUR)
                .cardToken(cardToken)
                .merchantName("Shop")
                .merchantCountry(MerchantCountry.GERMANY)
                .occurredAt(Instant.now())
                .createdAt(Instant.now())
                .externalId(UUID.randomUUID())
                .build();
    }
}

package com.zverev.scoring.kafka;

import com.zverev.dto.TransactionEvent;
import com.zverev.entity.Alert;
import com.zverev.entity.Transaction;
import com.zverev.entity.enums.*;
import com.zverev.exception.TransactionNotFoundException;
import com.zverev.repository.TransactionRepository;
import com.zverev.scoring.service.GuardFilterService;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.ArgumentCaptor;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.ValueOperations;

import java.math.BigDecimal;
import java.time.Duration;
import java.time.Instant;
import java.util.Optional;
import java.util.UUID;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.ArgumentMatchers.anyString;
import static org.mockito.ArgumentMatchers.eq;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
class TransactionEventConsumerTest {

    @Mock
    private TransactionRepository transactionRepository;

    @Mock
    private GuardFilterService guardFilterService;

    @Mock
    private StringRedisTemplate redisTemplate;

    @Mock
    private ValueOperations<String, String> valueOps;

    private TransactionEventConsumer consumer;

    @BeforeEach
    void setUp() {
        consumer = new TransactionEventConsumer(transactionRepository, guardFilterService, redisTemplate);
    }

    @Test
    @DisplayName("first event, no violations - saved as APPROVED")
    void firstEventNoViolations_approved() {
        UUID externalId = UUID.randomUUID();
        TransactionEvent event = event(externalId);
        Transaction tx = transaction(externalId);

        when(redisTemplate.opsForValue()).thenReturn(valueOps);
        when(valueOps.setIfAbsent(anyString(), eq("1"), eq(Duration.ofHours(24)))).thenReturn(true);
        when(transactionRepository.findByExternalId(externalId)).thenReturn(Optional.of(tx));

        consumer.consume(event);

        ArgumentCaptor<Transaction> captor = ArgumentCaptor.forClass(Transaction.class);
        verify(transactionRepository).save(captor.capture());
        assertThat(captor.getValue().getStatus()).isEqualTo(TransactionStatus.APPROVED);
        verify(guardFilterService).filter(tx);
    }

    @Test
    @DisplayName("critical alert - saved as DECLINED")
    void criticalAlert_declined() {
        UUID externalId = UUID.randomUUID();
        TransactionEvent event = event(externalId);
        Transaction tx = transaction(externalId);

        when(redisTemplate.opsForValue()).thenReturn(valueOps);
        when(valueOps.setIfAbsent(anyString(), eq("1"), eq(Duration.ofHours(24)))).thenReturn(true);
        when(transactionRepository.findByExternalId(externalId)).thenReturn(Optional.of(tx));
        doAnswer(inv -> {
            tx.addAlert(new Alert(Rule.VELOCITY, AlertSeverity.CRITICAL, "velocity", Instant.now()));
            return null;
        }).when(guardFilterService).filter(tx);

        consumer.consume(event);

        ArgumentCaptor<Transaction> captor = ArgumentCaptor.forClass(Transaction.class);
        verify(transactionRepository).save(captor.capture());
        assertThat(captor.getValue().getStatus()).isEqualTo(TransactionStatus.DECLINED);
    }

    @Test
    @DisplayName("high alert (non-critical) - saved as REVIEW")
    void highAlert_review() {
        UUID externalId = UUID.randomUUID();
        TransactionEvent event = event(externalId);
        Transaction tx = transaction(externalId);

        when(redisTemplate.opsForValue()).thenReturn(valueOps);
        when(valueOps.setIfAbsent(anyString(), eq("1"), eq(Duration.ofHours(24)))).thenReturn(true);
        when(transactionRepository.findByExternalId(externalId)).thenReturn(Optional.of(tx));
        doAnswer(inv -> {
            tx.addAlert(new Alert(Rule.HIGH_RISK_MERCHANT, AlertSeverity.HIGH, "merchant", Instant.now()));
            return null;
        }).when(guardFilterService).filter(tx);

        consumer.consume(event);

        ArgumentCaptor<Transaction> captor = ArgumentCaptor.forClass(Transaction.class);
        verify(transactionRepository).save(captor.capture());
        assertThat(captor.getValue().getStatus()).isEqualTo(TransactionStatus.REVIEW);
    }

    @Test
    @DisplayName("duplicate event - skipped, no save, no filter")
    void duplicateEvent_skipped() {
        UUID externalId = UUID.randomUUID();
        TransactionEvent event = event(externalId);

        when(redisTemplate.opsForValue()).thenReturn(valueOps);
        when(valueOps.setIfAbsent(anyString(), eq("1"), eq(Duration.ofHours(24)))).thenReturn(false);

        consumer.consume(event);

        verify(transactionRepository, never()).findByExternalId(any());
        verify(transactionRepository, never()).save(any());
        verify(guardFilterService, never()).filter(any());
    }

    @Test
    @DisplayName("transaction not found - TransactionNotFoundException")
    void notFound_throwsException() {
        UUID externalId = UUID.randomUUID();
        TransactionEvent event = event(externalId);

        when(redisTemplate.opsForValue()).thenReturn(valueOps);
        when(valueOps.setIfAbsent(anyString(), eq("1"), eq(Duration.ofHours(24)))).thenReturn(true);
        when(transactionRepository.findByExternalId(externalId)).thenReturn(Optional.empty());

        assertThatThrownBy(() -> consumer.consume(event))
                .isInstanceOf(TransactionNotFoundException.class)
                .hasMessageContaining(externalId.toString());

        verify(transactionRepository, never()).save(any());
        verify(guardFilterService, never()).filter(any());
    }

    private TransactionEvent event(UUID externalId) {
        return new TransactionEvent(externalId, "card-1", new BigDecimal("100"),
                CurrencyCode.EUR, "Shop", MerchantCountry.GERMANY, Instant.now());
    }

    private Transaction transaction(UUID externalId) {
        return Transaction.builder()
                .externalId(externalId)
                .cardToken("card-1")
                .amount(new BigDecimal("100"))
                .currencyCode(CurrencyCode.EUR)
                .merchantName("Shop")
                .merchantCountry(MerchantCountry.GERMANY)
                .occurredAt(Instant.now())
                .createdAt(Instant.now())
                .build();
    }
}
